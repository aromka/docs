---
title: "GET /campaigns/{id} — Retrieve a Full Campaign Record"
sidebarTitle: "Get Campaign"
description: "Fetch the full details of a single campaign by its unique ID, including current status, amounts raised, and accepted donation types."
---

Use this endpoint to retrieve the complete details of a single campaign. You'll need the campaign's unique identifier, which is returned when you [create a campaign](/api-reference/campaigns/create) or [list campaigns](/api-reference/campaigns/list). This endpoint is useful for checking real-time fundraising progress or verifying campaign configuration.

## Endpoint

```
GET https://api.crowdchange.co/v1/campaigns/{id}
```

## Path Parameters

<ParamField path="id" type="string" required>
  The unique identifier of the campaign to retrieve (e.g. `camp_abc123`).
</ParamField>

## Example Request

```bash
curl https://api.crowdchange.co/v1/campaigns/camp_abc123 \
  -H "Authorization: Bearer YOUR_API_KEY"
```

## Example Response

```json
{
  "data": {
    "id": "camp_abc123",
    "name": "2024 Annual Walk",
    "description": "Our annual fundraising walk for heart research.",
    "goal_amount": 10000000,
    "raised_amount": 4250000,
    "currency": "CAD",
    "status": "active",
    "donation_types": ["one_time", "monthly"],
    "start_date": "2024-03-01T00:00:00Z",
    "end_date": "2024-03-31T23:59:59Z",
    "page_url": "https://give.crowdchange.co/annual-walk-2024",
    "created_at": "2024-01-15T10:00:00Z",
    "updated_at": "2024-03-10T09:30:00Z"
  }
}
```

## Response Fields

<ResponseField name="data" type="object">
  The campaign object.

  <Expandable title="Campaign object fields">
    <ResponseField name="id" type="string">
      The unique identifier for the campaign (e.g. `camp_abc123`).
    </ResponseField>

    <ResponseField name="name" type="string">
      The display name of the campaign.
    </ResponseField>

    <ResponseField name="description" type="string">
      A human-readable description of the campaign's purpose and goals.
    </ResponseField>

    <ResponseField name="goal_amount" type="integer">
      The fundraising goal in cents (e.g. `10000000` = $100,000.00).
    </ResponseField>

    <ResponseField name="raised_amount" type="integer">
      The total amount raised so far, in cents.
    </ResponseField>

    <ResponseField name="currency" type="string">
      The ISO 4217 currency code for this campaign (e.g. `CAD`, `USD`).
    </ResponseField>

    <ResponseField name="status" type="string">
      The current lifecycle status of the campaign. One of: `draft`, `active`, `completed`, `archived`.
    </ResponseField>

    <ResponseField name="donation_types" type="array">
      The donation frequencies accepted by this campaign. Each element is one of: `one_time`, `monthly`, `annual`.
    </ResponseField>

    <ResponseField name="start_date" type="string">
      The campaign's start date and time in ISO 8601 format.
    </ResponseField>

    <ResponseField name="end_date" type="string">
      The campaign's end date and time in ISO 8601 format, or `null` if the campaign has no fixed end date.
    </ResponseField>

    <ResponseField name="page_url" type="string">
      The public URL of the campaign's donation page.
    </ResponseField>

    <ResponseField name="created_at" type="string">
      The timestamp when the campaign was created, in ISO 8601 format.
    </ResponseField>

    <ResponseField name="updated_at" type="string">
      The timestamp of the most recent update to the campaign, in ISO 8601 format.
    </ResponseField>
  </Expandable>
</ResponseField>

## Error: Campaign Not Found

If no campaign exists with the given ID, the API returns HTTP `404 Not Found`:

```json
{
  "error": {
    "code": "not_found",
    "message": "No campaign found with ID camp_abc123."
  }
}
```

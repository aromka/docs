---
title: "GET /donations/{id} — Retrieve a Full Donation Record"

---

Use this endpoint to retrieve the full details of a single donation record. You'll need the donation's unique identifier, which is returned when you [record a donation](/api-reference/donations/create) or [list donations](/api-reference/donations/list). This endpoint is useful for confirming donation status, looking up tribute details, or verifying matched gift amounts for a specific transaction.

## Endpoint

```
GET https://api.crowdchange.co/v1/donations/{id}
```

## Path Parameters

<ParamField path="id" type="string" required>
  The unique identifier of the donation to retrieve (e.g. `don_abc123`).
</ParamField>

## Example Request

```bash
curl https://api.crowdchange.co/v1/donations/don_abc123 \
  -H "Authorization: Bearer YOUR_API_KEY"
```

## Example Response

```json
{
  "data": {
    "id": "don_abc123",
    "campaign_id": "camp_abc123",
    "fundraiser_id": "fnd_def456",
    "amount": 10000,
    "currency": "CAD",
    "type": "one_time",
    "status": "completed",
    "donor": {
      "name": "Jane Smith",
      "email": "jane.smith@example.com",
      "anonymous": false
    },
    "tribute": {
      "type": "in_memory_of",
      "name": "John Smith"
    },
    "matched": true,
    "matched_amount": 10000,
    "created_at": "2024-03-10T14:35:00Z"
  }
}
```

## Response Fields

<ResponseField name="data" type="object">
  The donation object.

  <Expandable title="Donation object fields">
    <ResponseField name="id" type="string">
      The unique identifier for the donation (e.g. `don_abc123`).
    </ResponseField>

    <ResponseField name="campaign_id" type="string">
      The ID of the campaign this donation belongs to.
    </ResponseField>

    <ResponseField name="fundraiser_id" type="string | null">
      The ID of the fundraiser page this donation was made through, or `null` if it was donated directly to the campaign.
    </ResponseField>

    <ResponseField name="amount" type="integer">
      The donation amount in cents (e.g. `10000` = $100.00).
    </ResponseField>

    <ResponseField name="currency" type="string">
      The ISO 4217 currency code for this donation (e.g. `CAD`, `USD`).
    </ResponseField>

    <ResponseField name="type" type="string">
      The donation frequency or type. One of: `one_time`, `monthly`, `annual`, `pledge`.
    </ResponseField>

    <ResponseField name="status" type="string">
      The current processing status of the donation. One of: `pending`, `completed`, `failed`, `refunded`.
    </ResponseField>

    <ResponseField name="donor" type="object">
      Information about the donor who made this donation.

      <Expandable title="Donor fields">
        <ResponseField name="donor.name" type="string">
          The donor's full name. May be `"Anonymous"` if the donor chose to give anonymously.
        </ResponseField>

        <ResponseField name="donor.email" type="string">
          The donor's email address.
        </ResponseField>

        <ResponseField name="donor.anonymous" type="boolean">
          `true` if the donor chose to remain anonymous on the public campaign page.
        </ResponseField>
      </Expandable>
    </ResponseField>

    <ResponseField name="tribute" type="object | null">
      Tribute information if this donation was made in memory or in honour of someone. Returns `null` if no tribute was designated.

      <Expandable title="Tribute fields">
        <ResponseField name="tribute.type" type="string">
          The type of tribute. Either `in_memory_of` or `in_honour_of`.
        </ResponseField>

        <ResponseField name="tribute.name" type="string">
          The name of the person being honoured or remembered.
        </ResponseField>
      </Expandable>
    </ResponseField>

    <ResponseField name="matched" type="boolean">
      `true` if this donation was matched by a corporate or donor match program.
    </ResponseField>

    <ResponseField name="matched_amount" type="integer | null">
      The matched contribution amount in cents, or `null` if the donation was not matched. For example, `10000` = $100.00.
    </ResponseField>

    <ResponseField name="created_at" type="string">
      The timestamp when the donation was recorded, in ISO 8601 format.
    </ResponseField>
  </Expandable>
</ResponseField>

## Error: Donation Not Found

If no donation exists with the given ID, the API returns HTTP `404 Not Found`:

```json
{
  "error": {
    "code": "not_found",
    "message": "No donation found with ID don_abc123."
  }
}
```

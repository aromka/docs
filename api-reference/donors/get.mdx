---
title: "Get Donor Profile — Retrieve a Donor Record by ID"
sidebarTitle: "Get Donor"
description: "Fetch a single donor's complete profile by their CrowdChange ID, including contact details, address, lifetime giving totals, and applied tags."
---

Use this endpoint to retrieve the full profile for a specific donor by their CrowdChange ID. This is useful for displaying donor details in a custom portal, looking up lifetime giving history before a stewardship call, or verifying contact information before syncing a record to an external system.

## Endpoint

```
GET https://api.crowdchange.co/v1/donors/{id}
```

## Path Parameters

<ParamField path="id" type="string" required>
  The unique CrowdChange ID of the donor you want to retrieve (e.g. `dnr_abc123`).
</ParamField>

## Example Request

```bash
curl https://api.crowdchange.co/v1/donors/dnr_abc123 \
  -H "Authorization: Bearer YOUR_API_KEY"
```

## Example Response

```json
{
  "id": "dnr_abc123",
  "name": "Jane Smith",
  "email": "jane@example.com",
  "phone": "+1-416-555-0100",
  "address": {
    "street": "123 Main St",
    "city": "Toronto",
    "province": "ON",
    "postal_code": "M5V 1A1",
    "country": "CA"
  },
  "total_donated": 75000,
  "donation_count": 3,
  "first_donation_at": "2022-04-10T09:00:00Z",
  "last_donation_at": "2024-03-15T14:30:00Z",
  "tags": ["major-donor", "recurring"],
  "created_at": "2022-04-10T09:00:00Z"
}
```

## Response Fields

<ResponseField name="id" type="string">
  The unique identifier for this donor (e.g. `dnr_abc123`).
</ResponseField>

<ResponseField name="name" type="string">
  The donor's full name as entered at the time of their first donation.
</ResponseField>

<ResponseField name="email" type="string">
  The donor's email address.
</ResponseField>

<ResponseField name="phone" type="string | null">
  The donor's phone number, or `null` if not provided.
</ResponseField>

<ResponseField name="address" type="object | null">
  The donor's mailing address, or `null` if not provided.

  <Expandable title="Address fields">
    <ResponseField name="street" type="string">
      Street address including number and street name.
    </ResponseField>
    <ResponseField name="city" type="string">
      City name.
    </ResponseField>
    <ResponseField name="province" type="string">
      Province or state code (e.g. `ON`, `CA`, `NY`).
    </ResponseField>
    <ResponseField name="postal_code" type="string">
      Postal or ZIP code.
    </ResponseField>
    <ResponseField name="country" type="string">
      Two-letter ISO 3166-1 alpha-2 country code (e.g. `CA`, `US`).
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="total_donated" type="integer">
  The total amount donated by this donor across all campaigns, in cents. Divide by `100` to convert to dollars (e.g. `75000` = $750.00).
</ResponseField>

<ResponseField name="donation_count" type="integer">
  The total number of completed donations made by this donor across all campaigns.
</ResponseField>

<ResponseField name="first_donation_at" type="string">
  ISO 8601 timestamp of the donor's first completed donation.
</ResponseField>

<ResponseField name="last_donation_at" type="string">
  ISO 8601 timestamp of the donor's most recent completed donation.
</ResponseField>

<ResponseField name="tags" type="array of strings">
  Custom labels applied to this donor in the CrowdChange dashboard (e.g. `["major-donor", "recurring"]`). Returns an empty array if no tags have been applied.
</ResponseField>

<ResponseField name="created_at" type="string">
  ISO 8601 timestamp of when this donor record was first created in CrowdChange.
</ResponseField>

<Note>
  Donor profiles are created automatically the first time someone completes a donation on your CrowdChange campaign. You cannot create or delete donor records directly via the API — all donor management is handled through the CrowdChange dashboard or triggered by donation activity.
</Note>

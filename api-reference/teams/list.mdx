---
title: "List Fundraising Teams — CrowdChange Campaign Teams"
sidebarTitle: "List Teams"
description: "Retrieve a ranked list of peer-to-peer fundraising teams within a campaign, including amounts raised, member counts, and leaderboard positions."
---

Teams are groups of peer-to-peer fundraisers who rally together within a campaign to reach a shared goal. Use this endpoint to display a live leaderboard on your event website, integrate team standings into your own event app, or pull team performance data for post-campaign reporting.

## Endpoint

```
GET https://api.crowdchange.co/v1/teams
```

## Query Parameters

<ParamField query="campaign_id" type="string" required>
  The ID of the campaign to list teams for (e.g. `camp_abc123`). This parameter is required — teams always belong to a single campaign.
</ParamField>

<ParamField query="limit" type="integer">
  The number of team records to return per page. Defaults to `20`. Maximum is `100`.
</ParamField>

<ParamField query="cursor" type="string">
  A pagination cursor returned as `next_cursor` from a previous response. Pass this value to retrieve the next page of results.
</ParamField>

<ParamField query="sort" type="string">
  Controls the order in which teams are returned. Accepted values:

  - `raised_desc` *(default)* — highest amount raised first; this is standard leaderboard order.
  - `raised_asc` — lowest amount raised first.
  - `name_asc` — alphabetical by team name.
</ParamField>

## Example Request

```bash
curl "https://api.crowdchange.co/v1/teams?campaign_id=camp_abc123&sort=raised_desc" \
  -H "Authorization: Bearer YOUR_API_KEY"
```

## Example Response

```json
{
  "data": [
    {
      "id": "team_abc123",
      "campaign_id": "camp_abc123",
      "name": "Team Heart Warriors",
      "captain_name": "Bob Johnson",
      "captain_email": "bob@example.com",
      "goal_amount": 500000,
      "raised_amount": 342500,
      "member_count": 12,
      "rank": 1,
      "page_url": "https://give.crowdchange.co/annual-walk-2024/teams/heart-warriors",
      "created_at": "2024-01-20T08:00:00Z"
    }
  ],
  "next_cursor": null,
  "has_more": false
}
```

## Response Fields

<ResponseField name="data" type="array">
  An array of team objects for the specified campaign, sorted according to your `sort` parameter.

  <Expandable title="Team object fields">
    <ResponseField name="id" type="string">
      The unique identifier for this team (e.g. `team_abc123`).
    </ResponseField>

    <ResponseField name="campaign_id" type="string">
      The ID of the campaign this team belongs to.
    </ResponseField>

    <ResponseField name="name" type="string">
      The team's display name as set by the team captain.
    </ResponseField>

    <ResponseField name="captain_name" type="string">
      The full name of the team captain who created the team.
    </ResponseField>

    <ResponseField name="captain_email" type="string">
      The email address of the team captain.
    </ResponseField>

    <ResponseField name="goal_amount" type="integer | null">
      The team's fundraising goal in cents, or `null` if no goal was set. Divide by `100` to convert to dollars (e.g. `500000` = $5,000.00).
    </ResponseField>

    <ResponseField name="raised_amount" type="integer">
      The total amount raised by all team members combined, in cents. Divide by `100` to convert to dollars (e.g. `342500` = $3,425.00).
    </ResponseField>

    <ResponseField name="member_count" type="integer">
      The number of fundraisers currently on this team, including the captain.
    </ResponseField>

    <ResponseField name="rank" type="integer">
      The team's current leaderboard position within the campaign, ranked by `raised_amount` descending. A rank of `1` means this is the top-raising team.
    </ResponseField>

    <ResponseField name="page_url" type="string">
      The public URL for this team's fundraising page on CrowdChange.
    </ResponseField>

    <ResponseField name="created_at" type="string">
      ISO 8601 timestamp of when this team was created.
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="next_cursor" type="string | null">
  A cursor string to pass as the `cursor` query parameter in your next request to retrieve the following page of results. Returns `null` when there are no more pages.
</ResponseField>

<ResponseField name="has_more" type="boolean">
  `true` if additional pages of results are available beyond the current response.
</ResponseField>

<Tip>
  This endpoint is well-suited for powering a live leaderboard widget on your event day website or a lobby display screen. Poll the endpoint every 30–60 seconds with `sort=raised_desc` and render the top teams in real time — no manual updates needed as donations come in throughout the event.
</Tip>

<Note>
  Teams are created by participants directly within the CrowdChange platform — either during registration or from their fundraiser dashboard. You cannot create or delete teams via the API.
</Note>
